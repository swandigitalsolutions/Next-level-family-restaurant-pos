## Provenance note

Wikimedia Commons API documentation confirms that the Commons MediaWiki API is publicly accessible at `https://commons.wikimedia.org/w/api.php`, and that files are provided under the licenses specified on their description pages. The first automated Commons fetcher was rate-limited and returned many irrelevant search hits, so the integration uses the curated, real image-search catalog above for the visual asset set and will retain this manifest for review.
